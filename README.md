# Elbara Mouaffak - Personal Portfolio

Hey, I'm Elbara. I'm an AI Engineering student and freelance developer based in Algeria. This is the repository for my personal portfolio website.

I built this site to showcase my work in AI, workflow automation, and full-stack development. It includes a custom AI chat assistant (built with Groq & Supabase Edge Functions), interactive 3D visualizations, and a gallery of my n8n workflow templates.

## Tech Stack

- **Frontend**: React, TypeScript, Vite
- **Styling**: Tailwind CSS, Shadcn UI
- **Animations/3D**: Framer Motion, React Three Fiber
- **Backend & APIs**: Supabase edge functions, Groq (Llama-3.3-70b)
- **Workflow Automation**: n8n

## Running the project locally

If you want to spin this up on your own machine:

1. Clone the repo and install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```

*(Note: The AI chatbot relies on a deployed Supabase Edge Function and Groq API key, so you'll need to set up your own `.env` file with `VITE_SUPABASE_URL` and `VITE_SUPABASE_PUBLISHABLE_KEY` if you want to run the chat locally).*
